# 隧图 Tunnel 视觉参数

隧图延续深空、点阵天体和双股尾迹的风格。调优围绕三条主线：**明确的纵深**（门环被拧成向灭点收束的螺旋）、**持续的实体**（母舰/行星/环带/空间站/侦察机六槽位铺满行程周期，任何时刻至少一个、多数时候两个成形天体在画，进画第一秒就见实体）、**克制而绚丽的光影**（冷远暖近、双色星场、尽头辉光、ACES 黑位）。中央阅读区域始终压暗，供歌词阅读。

| 调整项 | 当前参数 | 观感提升 |
| --- | --- | --- |
| 天体排班 | 周期 CELESTIAL_CYCLE=1200，6 槽位按 200 等距排布（初始深度 -150/-320/-520/-720/-920/-1120）；可见窗口 -260..0（260 宽于 200 间距） | 任意时刻画面里都有实体且两批交叠，永不再出现「只剩光圈」的空档；开场 0 秒槽 0 母舰就在下半区凝结 |
| 弧形掠过轨迹 | 每槽一条 far→near 航线（fx,fy → nx,ny）；纵向 smoothstep（早早压离阅读带），母舰/侦察机横向 quad（贴镜头才快速甩向边角）；垂直航线摆动 amp 2~5、f 0.14~0.85，随逼近增强、随低频轻推 | 天体不再沿 z 轴直冲，而是沿 3D 弧线飞掠：母舰左下切弯、侦察机蛇行甩向左上角，画面始终有横向运动 |
| 压坡与俯仰 | bank 由横向速度解析导数驱动（上限母舰 0.26/侦察机 0.55 rad）；pitch 由纵向速度驱动（±0.12）；母舰额外 pitchBias +0.16（尾焰轴向下方收） | 舰体转弯时像真的在压弯、爬升，侦察机大坡度掠袭；金色拖焰始终不越过歌词阅读带 |
| 凝聚生命周期 | 远方成雾 -260 起可见 → -140 四次缓出凝聚 → -140..-80 黄金展示 → -80..-20 解体消散；近景散雾按 nearTame（-110..-30，1→0）收束；近景淡出 84→20，旗舰尾焰（aShade=4）96→42 更早隐没 | 远远看着是一团星云，逼近凝成实体，掠过镜头化成一小簇火花后隐没；长拖焰与舰体贴脸时都不糊屏 |
| 天体阵容 | 母舰 0.85（航线 fx16,fy10 → nx-48,ny-30，全程下半区）、行星 0.88/0.72（右侧）、环带 0.84（左上空域，倾角 0.72，带卡西尼缝）、空间站 1.2（右下，环+4 辐条+航行灯）、侦察机 0.8（高空蛇行，甩向左上角） | 五种图形轮廓都读得出来；航线按阅读带上下分区，体量近大远小，近处有压迫感、远处是点缀 |
| 天体材质 | 0.14 环境光 + 1.02 漫反射 + 0.38 边缘光（rim 指数 2.8），片元提饱和 1.22，核心 1.5/halo 0.24，点径 370/depth、上限 40px、基础尺寸 ×1.12 | 亮暗面反差强、松石行星/琥珀环带/骨白舰体颜色鲜艳；近镜掠点仍保持颗粒感不糊成块 |
| 纵深轮廓 | 高/中档 14 道、低档 8 道断弧；间距 110 世界单位，椭圆 96×58；远端强制透视再收 10%；螺旋扭转 s×0.00042 | 灭点集中、隧道像被拧着吸入尽头；静态截图也有旋转动势 |
| 空气透视与冷暖 | 远端门环压暗至 40%（640→span-60）；近处暖色混入 60%；门环片元提饱和 1.30 | 门环层层沉进黑里，冷远暖近，色温本身成为深度线索 |
| 星场 | 高档 640 远 + 110 近、低档 420+60；远/近视差 0.26/1；约 30% 星点走主题暖色；半径外缘 380；亮度地板 0.20+0.42；闪烁 ±18% | 星场铺满整个视高（含屏幕边缘），冷白与琥珀星点交错，密度足而不噪 |
| 层间视差 | 远星/近星/航道/天体/流光速度 = 里程 0.26/1/0.42/0.72/1.55 倍 | 远处沉稳、近处掠过，速度差拉开纵深 |
| 尾迹流光 | 沿轨脉冲速度 0.14；脉冲系数 0.52、着色增益 0.85、低频增益 0.35；片元提饱和 1.28 | 两股航道光珠持续奔涌，起拍明显变亮 |
| 跃迁流光 | 起步阈值 0.55、速度增益 0.5、低频 0.35；最大长度约 98 世界单位；约 30% 流线染主题暖色 | 巡航时就有稀疏流线，加速/底鼓整片拉长，冷暖相间 |
| 尽头辉光与暗角 | 单三角形全屏层（1 draw call、无纹理）：松石主晕 0.034/衰减 8.0 + 琥珀暖核 0.020/衰减 13，中心 y=0.13；暗角只压最远四角（r>0.78，最多 22%）；辉光随低频 0.9 系数呼吸、约 20s 漂移；阅读带只保留 35% | 隧道尽头「有光」且足够绚丽，视线轻收灭点；中央歌词区不被洗灰 |
| 背景地板 | 直接沿用主题底色（亮色主题线性通道上限 0.004 兜底），世界色向经典琥珀 #f2a900/松石 #76bfae 锚定 40%（歌词层仍完全跟随主题） | Midnight 等低饱和主题下世界不会被洗灰，黑场依旧但边缘星带稳定可见 |
| 曝光与输出 | ACES/sRGB，曝光 1.16 | 大屏明亮一档，高光不溢出，深空黑位保留 |
| 镜头推进 | z 轴 17s 周期 ±0.35 世界单位推拉巡航 + 低频最多 0.9 单位轻推（歌词缩放 <3%） | 始终有「在飞」的体感，重拍有轻微冲拳，不扰读词 |
| 镜头呼吸 | FOV 基线 56°，速度最多 3°，低频最多 1.6°，另加 17s 周期 ±0.7° 长呼吸（与 z 轴同频）；阻尼 0.32s | 画面持续缓慢换气；单帧变化 <0.006°，30/60/120Hz 收敛一致 |
| 节拍环 | 起音上升沿触发，冷却 0.48s，寿命 1.2s，池容量 2，透明度上限 0.20；四次缓出 26→108 弹开并沿轴滑行至 z≈-116 | 每拍干脆的局部回应，持续低频不叠加，暂停冻结、seek 清环 |
| 轮廓呼吸 | 正弦缩放 ±1.6%，低频额外 ±1.2%（motion=1） | 门环有生命感，结构稳定 |

构建代码位于 `tools/tunnel-stage/src/world.js` 与 `main.js`；以上是视觉默认值。现有「星流」「天体」开关、主题和歌词设置继续有效，没有新增设置项或依赖。氛围层跟随星流开关与 reduced-motion：关闭星流或开启系统减弱动效时，辉光/暗角与其余背景元素一同隐藏、机位归零；轨迹摆动与压坡在减弱动效下随 motion 归零，航线与凝聚只依赖 (depth, sceneTime)，seek 落点和顺播完全一致。

性能方面，星场回绕在 GPU，频谱复用缓冲，关闭天体时跳过数组更新；轨迹/压坡/俯仰解算在槽位级完成（每槽每帧一次，不进点循环）。低档天体 7,200 点、流光 110 条、门环 8 道、星场 480 颗；高档星场 750 颗、门环 14 道。纵深轮廓与氛围层各只增加一次 draw call（无全屏 Bloom、无多遍模糊、无纹理）。像素预算继续为低/中/高 190/360/620 万。headless Chrome 受控采样：1080p 约 165fps、4K 约 85fps、低档 1080p 约 160fps，几何/纹理驻留稳定（真实舞台帧率仍需在目标显卡、分辨率和 LED 输出链路上验收，本机采样不作硬件帧率保证）。

暂停后同值时钟和频谱输入不再持续触发绘制，恢复 4fps 空闲预算；减弱动效冻结背景运动并关闭镜头滚转、FOV 呼吸与镜头推进，歌词时间继续更新；降档重建移除旧画布。

验证命令：

```text
node tools/tunnel-stage/build.mjs
node scripts/check-tunnel-stage.js
node scripts/check-tunnel-motion-browser.js
node scripts/check-tunnel-stage-browser.js
node scripts/check-frontend.js
```

浏览器脚本需要 Playwright 和 Chromium/Chrome，可用 `PLAYWRIGHT_MODULE` 指定已安装的模块。完整播放器测试用 `HERTZ_BIN` 指向包含最新前端资源的二进制；独立场景测试直接读取当前 bundle。

在 60Hz 受控测试中，乐句切换的最大 FOV 单帧变化约 0.066°（门限 0.25°），30/60/120Hz 下 FOV 收敛差 <0.02°，暂停两秒的提交帧数为 8（门限 9）。已保存 1080p、4K 显示窗口及低档的静音/高能量截图（output/playwright/tunnel-motion/after）。
