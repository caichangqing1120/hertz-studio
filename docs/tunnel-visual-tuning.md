# 隧图 Tunnel 视觉参数

隧图延续深空、点阵天体和双股尾迹的风格。本轮调优围绕「更明确的纵深、更强的明暗对比、持续但克制的节奏」展开：门环被拧成向灭点收束的螺旋，隧道尽头点起一小片双色辉光，镜头有了同频的呼吸与推进。中央阅读区域始终压暗，供歌词阅读。

| 调整项 | 当前参数 | 观感提升 |
| --- | --- | --- |
| 纵深轮廓 | 高/中档 14 道、低档 8 道断弧；间距 110 世界单位，椭圆半径 96 × 58；远端门环按深度再收 10%（强制透视） | 灭点更集中，近大远小的吸入感一眼成立；断弧保持纤细（smoothstep 0.12/0.28），不堆线条 |
| 螺旋扭转 | 门环角度随里程增加 `s × 0.00042`（整段可见行程约转过 37°，相邻环约 2.6°），随 warp 开关/reduced 归零 | 隧道像被缓缓拧着吸向尽头，静止截图也有旋转动势；回绕两端淡入淡出不变 |
| 空气透视 | 远端门环颜色压暗至 35%（640 → span-60 世界单位渐变），近端 vNear 过渡 70 → 700 | 门环一层层沉进黑里，远中近层次分离，不再是一圈圈等亮的线 |
| 冷远暖近 | 近处最多混入 56% 主题主色（原 42%），远端保持辅色 | 掠到眼前的环偏暖、远环偏冷，色温本身成为深度线索 |
| 层间视差 | 远星/近星/航道/天体/流光速度分别为里程的 0.26/1/0.42/0.72/1.55 倍；星场高 590 颗（480 远 + 110 近）、低 360 颗 | 远星更沉稳（0.32→0.26）、近处掠过更快，速度差拉开纵深；星点更密但不加粒子系统 |
| 尽头辉光与暗角 | 单三角形全屏层（1 个 draw call、无纹理）：松石主晕（系数 0.022、衰减 9.5）+ 琥珀暖核（0.013、衰减 16），中心位于视口 y=0.14；暗角边缘最多再沉 62%；辉光随低频以 0.8 系数呼吸、约 20s 缓慢漂移；中央歌词带只保留 35% | 隧道尽头「有光」，配合暗角把视线锁进灭点；辉光峰值约 20/255 且小而紧，只点氛围不洗灰黑场，也不干扰读词 |
| 天体材质 | 0.13 环境光 + 0.92 漫反射 + 0.34 边缘光（rim 指数 2.8），光点核心 1.4、halo 0.20 | 环境光压低、亮面与轮廓光抬升，行星/空间站亮暗面反差更大、体积感更强 |
| 曝光与输出 | ACES/sRGB，曝光 1.06 → 1.10；亮色主题背景线性通道上限 0.004 | 大屏上整体提亮一档但高光不溢出，继续保住深空黑位 |
| 尾迹流光 | 沿轨脉冲速度 0.11 → 0.14；脉冲亮度系数 0.42 → 0.52、着色增益 0.55 → 0.70；低频增益 0.25 → 0.35 | 两股航道上的光珠持续向前奔涌，起拍时明显变亮，节奏写在轨道上而不是靠堆特效 |
| 跃迁流光 | 起步阈值 0.65 → 0.55、速度增益 0.42 → 0.5、低频加成 0.25 → 0.35；最大长度 26+72 ≈ 98 世界单位 | 巡航时就有稀疏流线，加速/底鼓一进来整片拉长，速度感随音乐起伏 |
| 镜头推进 | z 轴推进 = 17s 周期 ±0.35 世界单位的缓慢推拉巡航 + 低频最多 0.9 单位的轻推 | 观众始终有「在飞」的体感，重拍有轻微冲拳；歌词平面在 z=-34，缩放 <3%，不打扰阅读 |
| 镜头呼吸 | FOV 基线 56°，速度最多 3°，低频最多 1.6°，另加 17s 周期 ±0.7° 长呼吸（与 z 轴推进同频 0.37/0.39 rad/s）；阻尼时间常数 0.32s | FOV 与推拉同频「换气」，画面持续流动；单帧变化 <0.006°，30/60/120Hz 收敛一致 |
| 节拍环 | 起音上升沿触发，冷却 0.48s，寿命 1.2s，池容量 2，透明度上限 0.20；四次缓出，26 → 108 快速弹开并沿轴滑行到 z≈-116 | 每拍一个干脆的局部回应，扩散先快后慢更有冲击；持续低频不会叠加，暂停冻结、seek 清除旧环 |
| 轮廓呼吸 | 正弦缩放 ±1.6%，低频额外最多 1.2%（默认 motion=1） | 门环有生命感，结构依旧稳定 |
| 门框与星点 | 门框弧 0.09 + 低频 0.12，逐字亮线 0.40 + 低频 0.15；星点闪烁振幅 0.12 → 0.18 | 歌词前方的舞台与节拍同步轻微起伏；星点更灵动但不喧闹 |

构建代码位于 `tools/tunnel-stage/src/world.js` 与 `main.js`；以上是视觉默认值。现有「星流」「天体」开关、主题和歌词设置继续有效，没有新增设置项或依赖。氛围层跟随星流开关与 reduced-motion：关闭星流或开启系统减弱动效时，辉光/暗角与其余背景元素一同隐藏、机位归零。

性能方面，星场回绕在 GPU，频谱复用缓冲，关闭天体时跳过数组更新；低档天体 7,200 点、流光 110 条、门环 8 道；高档星场 590 颗、门环 14 道。纵深轮廓与氛围层各只增加一次 draw call（无全屏 Bloom、无多遍模糊、无纹理）。像素预算继续为低/中/高 190/360/620 万，4K 显示窗口按预算缩放内部渲染尺寸。headless Chrome 受控采样：1080p 约 121fps、4K 约 81fps、低档 1080p 约 133fps，几何/纹理驻留稳定（真实舞台帧率仍需在目标显卡、分辨率和 LED 输出链路上验收，本机采样不作硬件帧率保证）。

暂停后同值时钟和频谱输入不再持续触发绘制，恢复 4fps 空闲预算；减弱动效冻结背景运动并关闭镜头滚转、FOV 呼吸与镜头推进，歌词时间继续更新；降档重建移除旧画布。

验证命令：

```text
node tools/tunnel-stage/build.mjs
node scripts/check-tunnel-stage.js
node scripts/check-tunnel-motion-browser.js
node scripts/check-tunnel-stage-browser.js
node scripts/check-frontend.js
```

浏览器脚本需要 Playwright 和 Chromium/Chrome，可用 `PLAYWRIGHT_MODULE` 指定已安装的模块。完整播放器测试用 `HERTZ_BIN` 指向包含最新前端资源的二进制；独立场景测试直接读取当前 bundle。

在 60Hz 受控测试中，乐句切换的最大 FOV 单帧变化约 0.066°（门限 0.25°），30/60/120Hz 下 FOV 收敛差 <0.02°，暂停两秒的提交帧数为 8（门限 9）。已保存 1080p、4K 显示窗口及低档的静音/高能量截图（output/playwright/tunnel-motion/after）。
