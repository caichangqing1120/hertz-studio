# 镜台 Diorama 视觉参数

镜台延续「末班车夜行」的基调：孤寂、镜面水、沿途站牌。本轮迭代不新增设置项、
不改交互，只做画面与动效的增量 —— 主轴是**纵深分层**：前景 / 中景 / 背景
三段各自有不同的掠过速度、雾浓度与散焦尺度，纵深由「视差速度 + 大气雾 +
散焦大小」三件事共同给出。

| 调整项 | 当前参数 | 观感提升 |
| --- | --- | --- |
| 大气雾 | FogExp2 密度 0.00082，雾色 = 地平线色 × 0.92 | 轨道/站台/草丛越远越淡，与水面的 uFade (180,1500m) 接上；天穹/星野/脊线不吃雾，剪影靠自身极暗立住 |
| 地平线雾带 | 天穹着色器内高斯带 σ=0.055，强度 uHaze=0.5，方位厚度 ±45% 起伏 | 远方有「低雾贴着水面」的层次，随能量轻微抬升；零额外 draw call |
| 前景草丛 | 3100 丛（medium 2000 / low 1100），横向 1.62~2.67m，高 0.45~1.3m，三角锥实例化 | 离镜头最近的东西掠得最快，是纵深最便宜的来源；风摆在顶点着色器里按 world 位置取相位 |
| 道床 | 3.9m 宽 × 0.06m 高暗色路基 | 钢轨不再悬在水面上，接触阴影有处可落 |
| 信号机 | 间距 214m，横 2.28m，暖 62% / 冷 38% 交替 | 中景一排匀速掠过的光点；灯头自发光 + glow 层软光斑，水里自然出现竖向倒影 |
| 灯晕场 | 52 点（站台灯 + 信号机灯 + 5 团低雾）单 Points；透视缩放，26m 贴脸淡出、430m 没入雾 | 灯从雾里「浮现再退场」；低雾团走相机相对坐标 + 固定像素尺寸 |
| 浮尘 | 620 粒（medium 360 / low 170），沿轨 260m 窗口按行驶里程取模循环 | 水汽/浮尘从前方掠向身后；粒子分布是播放时间的纯函数，暂停即静止、seek 一致 |
| 散焦光斑 | 14 枚（medium 8 / low 关），z −3.5~−18m，点径钳 12~130px，α≈0.028 | 镜头前的失焦光斑 = 景深虚化的视觉线索；起音时轻轻一跳，是贴身的节奏反馈 |
| 体积光锥 | 长 58m、底半径 9.8m，壳层 rim 亮、近远两端淡入淡出，强度 0.05×(0.75+能量+起音) | 车头灯在雾里的光路，「有人在夜里赶路」；反射 pass 里整层隐藏（镜像后方向是错的） |
| 接触阴影 | 站台脚下 + 信号机柱脚，径向渐变贴片，1 个 InstancedMesh | 物体「踩在地上」而不是浮着；不用 shadow map（直线长轨道只会得到一张糊掉的巨图） |
| 灯光三件套 | 天光 hemi 0.8 冷 · 月灯 0.95 冷 · 城市余晖 0.32 暖（从月位对面打来） | 冷暖对峙：月光的蓝 vs 站牌/车灯的暖 |
| 车头灯 | 85 × (0.85 + 起音×0.5 + 能量×0.25)，距 60m | 近处轨面与牌面的温度随节奏呼吸 |
| 环境反射 | 天穹渐变烘 PMREM（挂载/换色各一次），environmentIntensity 0.6，钢轨 envMapIntensity 1.5 | 金属件读得出夜空反射，不再是死黑一片；烘失败静默跳过 |
| 水面菲涅尔 | mix 因子 0.40 + 0.60 × grazing^1.35 | 掠射角越平反射越强，脚下的水几乎只剩深水色 —— 镜面「能照见东西」集中在画面中上段 |
| 水面近场 | × mix(0.82, 1.0, smoothstep(4,60,dist)) | 脚下水面让位给中景倒影与月光水路；同时保住「下亮上暗」的镜面关系 |
| 冷暖分离 | 深水乘 mix(1, 辅色×1.3+0.1, 0.55) 的 0.34−0.24×grazing | 水面自带从冷到暖的纵深梯度 |
| 月光水路 | pow^60 × 0.20 + pow^11 × 0.05（近窄远宽两瓣） | 月光在水上拉出一条主路 + 一片余晖 |
| 相机呼吸 | FOV ±0.85°（0.187/0.071Hz 叠加）、注视前距 ±6%、眼高 ±0.055m | 像坐在车厢里随路面起伏；全部是 t 的纯函数，seek 不变量不破 |
| 月轮呼吸 | 尺度 ±(能量×5% + 起音×3%) | 天上也有生命感 |
| 站牌背光晕 | 径向贴片，α = 演唱激活 × (0.14 + glow×0.2) | 有字在唱时牌从背后透光，没唱时只是块牌子 |
| 泛光/曝光 | bloom 0.52 / 0.72 / 0.7，曝光 1.18，胶片颗粒 ±0.03 保留 | 只有真的亮的东西起晕，黑位守住孤寂感 |

## 契约同步

`check-diorama-stage-browser.js` 两处判据跟着画面升级换成了更硬的量：

- **构图**：原「上行 vs 下行和差 > 15」在基线上就不稳（注视站牌的机位周期里
  月亮入画、道床占底部行的比例变化，单帧实测 −29..+1）。改为**中段（地平线
  光带+雾+倒影）对顶段（暗星空）的 5 帧中位数差 > 60**（实测 190~360）——
  画面平坦才会归零，同样表达「有天地分区」。
- **歌词/反射开关**：改为**冻结时钟后比像素**（`__freeze` → 等包络静息 →
  前后帧三行最大差 > 4）。世界静止时差异只可能来自被测对象；seek 必须落在
  「牌还在前方视距里」的窗口（VERSE+450ms），再晚牌甩到相机身后，差值恒 0。
- 新增「纵深分层齐全」断言：`stats().layers` 里草丛 ≥1100、灯晕 ≥40、浮尘
  ≥170、散焦/体积光/接触阴影在场、雾密度在 0.0004~0.0016。

构建链：`tools/diorama-stage/src/world.js`（场景）+ `camera.js`（机位）+
`lyrics.js`（站牌背光晕）→ `node build.mjs` → `cargo build` → 两份契约。
所有新增层在 `world.js` 顶部常量块集中可调（FOG_DENSITY / MOTE_RANGE /
SHAFT_* / BOKEH_* / GLOW_* / WIND_* 等）。
