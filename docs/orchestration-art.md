# 高级编排 · 四处风景

四张场景选择插画采用统一的矢量绘画风格，强调自然轮廓、统一受光方向和前后遮挡。保留四组丰富的色彩：蔚蓝与蜜桃云影、珊瑚金与蓝紫海水、靛蓝与琥珀车窗、翡翠绿与蜂蜜金光。四图没有复用跨场景的云、草叶或装饰路径。

本轮重画了四张 SVG，并修正真实舞台的自动镜头晃动。场景选择插画与真实舞台的 GLSL 绘画分别由原有注册表和着色器负责；本次没有用 SVG 替代舞台着色器。

### 第三轮：《JOJO》日漫风重绘（2026-10-12）

在方案 A（新增「动画绘景」SVG 舞台来源，见下节）落地之后，四张底稿又按《JOJO 的奇妙冒险》的日漫路子重做了一遍，目标是甩掉"廉价矢量插画"的观感。四件事，逐张落实：

- **线条**：所有主体轮廓从"只有色块边界"改成上墨线（`stroke` + `stroke-linejoin: round`，宽度 1–4 按体量分档）；受光脊另走一路暖色边缘光（`#ffd9a8` / `#e8e0a8` / `#d8ecec`）。实现上全部写成既有路径的**属性**，不新增元素。
- **色彩**：渐变提饱和、暖光上抬（例如天空 `#1565d8→#58bde8→#ffd9a0`，海岸 `#58479e→#f0629b→#ff8a5c→#ffe3a0`）。同时**刻意砍掉冗余渐变节点**——`stop` 也是 DOM 元素，扁平色阶既更像 cel 动画，也直接省了元素预算（海岸 −5、森林 −6）。
- **光影**：一律"受光体 + 硬边暗部"两段平涂，不用柔边过渡。云是这套做法的样板：先画整块剪影（暗调），再把**同一条轮廓下移 34px 的反向路径**叠上去当受光带，两条线之间就是那条硬分界。
- **造型**：桥墩分出受光面/背光面并给拱券加内圈阴影环（`A37 37 … A45 45 …` 同心弧带）；列车加车内暖光对地面的落影；石块、贝壳补接地阴影；森林的两根前景树干补树根投影，中景树影按空气透视重新配了远近两档浓度。

元素预算（`svg *` 计数，上限 110）：晴空云海 76、黄昏海岸 100、月下列车 97、森间灯火 100。

## 画面描述与循环

### 1. 晴空云海

**画面提示词：** 晨光里的高山垭口。蔚蓝晴空逐渐过渡到浅金色空气，主峰偏左，不规则雪线沿山脊破碎，沟壑、岩层和受光面统一朝向右上方的光源。远山呈淡蓝紫，近壁带冷青色。奶油白云团以饱满的弧面、蜜桃反光和薰衣草色暗部体现体积，前后交叠，薄雾缓缓穿过山腰。固定镜头，山不动，只见空气流动。

**场景与循环：** 放空与舒缓聆听。26、19、15.3 秒云团沿水平方向错相流动，11.3 秒山腰薄雾独立变化；43 秒卷云换相，29.3 秒一行候鸟掠空，9.8 秒日光呼吸。山峰与岩壁始终固定。

### 2. 黄昏海岸

**画面提示词：** 夕照中的退潮海湾。珊瑚粉与杏金天空映在蓝紫海面，落日的碎光随远近改变疏密。左侧风化岩壁托起一座小灯塔，裂隙、暗面与岸脚白浪交代尺度；弧形沙岸从右侧伸向近景，湿沙有冷紫反光，干沙温暖。浪花由断续细线组成，近处石块带短影。地平线固定，潮水层层推进。

**场景与循环：** 慢歌与情绪过渡。7.3、9.7 秒涌浪在完全透明时换相，11.9 秒岸线往复，10.9 秒碎光舒展，8.3 秒落日余晖呼吸，12.9 秒波纹缓移。

### 3. 月下列车 · 细雨

**画面提示词：** 蒙蒙细雨里的月夜山谷。月牙映照层叠靛蓝山脊，细长的青蓝客车带着琥珀车窗横穿石拱桥，车窗框、玻璃反光和暗处乘客剪影克制清晰。桥洞内侧有冷暗阴影，拱石缝隙承接月光，谷底细溪与薄雾隐约可见。两层细雨持续斜落，桥、山和接触网全部静止，只有列车、雨丝与薄雾移动。

**场景与循环：** 夜行与稳定节奏。24.3 秒列车在画外换相；6.1、4.6 秒细雨沿相邻雨幕连续衔接，14.9 秒薄雾独立漂移，6.7 秒月晕呼吸，7.3 秒车窗微光明暗。接触网与桥梁不移动。

### 4. 森间灯火

**画面提示词：** 雨后翡翠色的林间。树干自然收细、弯曲分叉，近处树皮深青，远处树木融入薄荷色空气。树冠与枝叶围出中央的浅金色林隙，蜿蜒小径绕过带苔色的石块，前景蕨叶与林下小叶疏密错落。右侧一盏小灯投出蜂蜜色光晕，三枚萤火缓缓游移。树木、灯具和光束方向稳定，仅萤火、灯的亮度与一簇蕨叶轻微变化。

**场景与循环：** 专注与安静陪伴。萤火的横纵位移与亮度使用不同周期，灯光 7.7 秒、斜光亮度 23.3 秒独立变化，蕨叶以 8.3 秒周期轻微转动。树干、灯具和光束方向保持固定。

四幅作品均为确定性的有限周期动画。多个不同周期与负相位共同运行，组合画面长时间不易察觉重复，不声称数学意义上的永不重复。往复动画首尾位置及速度连续；单向运行元素在透明或完全离开画幅时换相。

## 稳定构图

- SVG 的山峰、地平线、岩壁、桥梁、接触网、树干和灯具保持固定；取消卡片悬停上移/点击缩放、接触网掠过、灯具与大面积光束摆动。
- 真实舞台由 CreativeStage 在既有参数解析和相机合成处落实固定构图。动画绘景始终固定；普通三维场景在高级编排打开时固定，关闭后恢复自动镜头。
- 抑制自动漂移、节拍冲击、悬停视差、松手惯性、镜头叠加层、自动导演与入画补间中的镜头贡献，以及镜头/整体缩放旋转的音频绑定。
- 场景时间和非镜头音频响应继续推进。手动机位、直接拖动和明确编写的 cue 保留，保存的预置与绑定不改写。Workshop 只提供只读编辑状态，不接管相机或新增时钟。

## 实现与性能

- 唯一插画源：plugin/ui/creative-anime.js 的 presentation.art，viewBox 为 640 × 400。
- 动画：plugin/ui/creative-anime.css，只改变 transform / opacity。共 33 个运动层；每图少于 110 个 SVG 子元素，细节通过合并路径表达。无滤镜、动态模糊、位图、视频和新依赖。
- 生命周期：Workshop 的单个 IntersectionObserver 观察当前画册；离屏、隐藏页面、关闭或切换页签时暂停，重建前断开旧观察器。无新增 rAF 或轮询。
- 响应式：画册容器 ≤460px 切换单列；固定 8:5 画幅保持完整构图，预留尺寸避免布局跳动。
- 控制：Tab 聚焦画册，空格暂停/继续，左右方向键在 0.5×–1.5× 之间调速；也可使用按钮。Web Animations updatePlaybackRate 保持当前相位。独立 SVG 自行循环，键盘控制由 HTML/应用画册提供。
- 系统与应用的减弱动态效果设置显示静态画面。
